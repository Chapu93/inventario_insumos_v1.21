## 🎓 Función Principal a Conocer

```php
// En: includes/auth.php

function tienePermiso($modulo, $accion) {
    // Retorna: true si usuario tiene permiso, false si no
    // Módulos: 'insumos', 'telecom', 'sedes', 'areas', etc.
    // Acciones: 'ver', 'crear', 'editar', 'eliminar', 'devolver'
}
```

**Usar en HTML:**
```php
<?php if (tienePermiso('modulo', 'accion')): ?>
    <button>...</button>
<?php endif; ?>
```
